Sahayak – AI-Powered Chrome Side Panel Assistant

About

Sahayak is an AI-powered Chrome extension designed to help users interact with webpages more easily and safely.

Features

* Summarize Page: Extracts and displays webpage content.
* Translate: Uses Gemini AI to translate webpage content into Hindi.
* Detect Elements: Identifies buttons, links, and input fields on webpages.
* Approved Errand: Prepares an email draft and asks for user approval before opening it in an email application.

Technologies Used

* HTML
* CSS
* JavaScript
* Chrome Extension Manifest V3
* Google Gemini API

Installation

1. Download or clone this repository.
2. Open Google Chrome.
3. Visit chrome://extensions.
4. Enable Developer mode.
5. Click Load unpacked.
6. Select the project folder containing manifest.json.

Gemini API Setup

1. Create a Gemini API key using Google AI Studio.
2. Open the Sahayak extension.
3. Enter your API key.
4. Click Save API Key.

Never publish your personal API key in this repository.

Safety

Sahayak asks for user confirmation before opening an email draft. The user reviews and sends the email manually.
